# СИГНАЛЫ — приложение игрока и редактор пакетов

Приложение для Android, через которое игроки ролевой игры «СИГНАЛЫ» получают данные: профиль персонажа, тексты, картинки и аудиозаписи. Данные открываются кодами и QR-кодами. Плюс редактор на компьютере: в нём собирается всё наполнение игры.

**Сюжетных текстов и кодов игры в этом репозитории нет**: он открытый. Наполнение хранится в файле пакета `.sgpack` у автора.

## Из чего состоит

| Что | Где берётся | Для кого |
|---|---|---|
| `signaly-<версия>.apk` | Релизы → последний `build-N` | Ставится на телефоны игроков (Android 7 и новее) |
| `signaly-editor-<версия>.html` | Там же | Редактор. Открыть двойным щелчком в Chrome, устанавливать ничего не нужно |
| `<название>-vN.sgpack` | Сохраняет редактор | Пакет игры: все тексты, коды, картинки, mp3. Загружается в приложение |

Один APK подходит для всех версий игры. Когда меняются тексты или коды, достаточно сохранить новый пакет и загрузить его в телефоны. Новый APK нужен, только если изменилось само приложение.

## Сеть игры (с версии сессии П3)
Телефоны связываются через **центр** — один из телефонов с этим же приложением, в общей сети Wi-Fi (роутер или точка доступа, интернет не нужен).
1. На телефоне-центре: мастерский код → «Пульт мастера (сеть)» → «Запустить центр на этом телефоне». Появится QR «СЕТЬ».
2. На остальных: на экране входа «СКАНЕР QR» → QR «СЕТЬ». В шапке ● — связь есть.
3. Пульт мастера: глава для всех, аварийный режим, уведомления, сбои, обратный отсчёт, голосования, переписка, сброс центра перед новой игрой.

В пакете (редактор): «Приборы» (градусник и т. п. — только камера), «Сеть и события» (уведомления, аварии, сбои и состояния, правила, голосования), у кодов — ответы по счёту, ограничения выдачи («ампула пуста»), подписи, особые ответы персонажам, действия. Протокол для терминала Twine — `docs/06_NETWORK.md`.

## Как пользоваться

**Редактор (компьютер, Chrome):**
1. Откройте `signaly-editor-….html`. Черновик сохраняется в браузере сам.
2. Вкладки по порядку:
   - «Общее»: название и мастерский код.
   - «Главы и стили»: оформление каждой главы и код перехода.
   - «Аккаунты»: персонажи, коды входа, Мультипаспорт.
   - «Блоки данных»: тексты, картинки, звук; кому видны и с какой главы.
   - «Коды»: что открывает код, кому, что видят остальные.
3. «Медиа» — все файлы и размер пакета. «Проверка» — ошибки. «Предпросмотр» — телефон на экране.
4. «QR-коды»: любой код превращается в QR и сохраняется в JPG. Гамма: зелёный на чёрном, чёрный на зелёном, чёрный на белом или свои цвета. Картинку можно вставить в терминал Twine или наклеить на реквизит.
5. «Сохранить пакет» сохраняет файл `.sgpack`, номер версии растёт сам.

**Телефон:**
1. Установите APK. Android попросит разрешить установку из этого источника.
2. Откройте приложение, нажмите «Загрузить пакет» и выберите `.sgpack`. После загрузки файл из «Загрузок» можно удалить: пакет хранится внутри приложения.
3. Мастер вводит код входа персонажа, и телефон остаётся в этом аккаунте.
4. **Мастерский код** на вкладке «Код» или как QR открывает режим мастера:
   - сменить аккаунт;
   - выставить главу;
   - сбросить прогресс;
   - загрузить новый пакет (открытые данные и глава при этом сохраняются);
   - посмотреть версии пакета и приложения.

## Для разработки

```
npm ci
npm run build                               # dist/editor.html, dist/www/index.html
node tests/e2e.mjs playwright /tmp/shots    # сквозная проверка (нужны ffmpeg, python3 + Pillow)
python3 tools/make-icons.py                 # иконка и заставка Android
```

Сборку APK делает GitHub Actions (`.github/workflows/build.yml`): Capacitor 8 + Gradle. Каждый пуш проверяется, пуш в `main` даёт релиз.

**Подпись APK.** Все сборки подписываются одним ключом, иначе новая версия не встанет поверх старой. По умолчанию это общий ключ `android/keystore/signaly-public.jks`, пароль к нему лежит в workflow. Ключ открытый, поэтому теоретически кто-то может подписать им чужую сборку; для игры это неважно. Чтобы перейти на закрытый ключ, задайте в настройках репозитория секреты `SG_KEYSTORE_B64` (ключ в base64) и `SG_KEYSTORE_PASSWORD`, тогда сборка возьмёт их. Важно: после смены ключа старую версию на телефонах нужно удалить, иначе новая не встанет.
